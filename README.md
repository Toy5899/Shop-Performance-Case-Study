# Online Shop Performance Analysis

## Project Overview
This project analyses the performance of an online shop from January 2024 to June 2026. The analysis focuses on revenue, orders, products, customers, payments and discounts.

## Tools Used
- Python
- Pandas
- Databricks
- Looker Studio
- GitHub

## Data Preparation
The project used four datasets: Orders, Products, Customers and Payments. The data was cleaned, checked for missing values and duplicates, and joined to create one final dataset for analysis.

Revenue and Actual Revenue were calculated, with only completed and paid orders counted as Actual Revenue.

## Dashboard
A Looker Studio dashboard was created to analyse:
- Revenue and orders
- Monthly revenue trends
- Product and category performance
- Customer and city performance
- Order and payment performance
- Discount performance

## Key Insights
- The shop generated approximately 2.99M in Actual Revenue.
- Electronics was the highest revenue-generating category.
- Accessories recorded the highest number of units sold.
- Tehran was the highest-value city.
- Regular customers generated the most revenue.
- Revenue declined during the first half of 2026.
- Higher discounts did not significantly increase order size.

## Recommendations
- Focus on high-value products and categories.
- Review the discount strategy.
- Investigate the revenue decline experienced in 2026.

## Conclusion
The analysis provided a clear overview of the shop's sales, customer and operational performance and identified opportunities for improving revenue and business performance.
